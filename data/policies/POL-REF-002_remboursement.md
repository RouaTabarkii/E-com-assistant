# Politique de remboursement


## 1. Principe
1.1 Un remboursement est émis lorsqu'une commande est annulée, retournée conformément à POL-RET-001, ou non livrée selon POL-DEL-003.
1.2 Le remboursement porte sur le prix du produit. Les frais de livraison initiaux sont remboursés dans les cas listés en 3.

## 2. Délais
2.1 Le remboursement est déclenché dans un délai maximal de **10 jours ouvrés** après la validation du retour par le vendeur.
2.2 Pour une commande annulée avant expédition, le remboursement est déclenché sous 3 jours ouvrés.
2.3 Le délai effectif d'arrivée des fonds dépend du moyen de paiement (section 4).

## 3. Remboursement des frais de livraison
3.1 Les frais de livraison sont remboursés : en cas d'annulation avant expédition ; en cas de produit défectueux ou non conforme ; en cas de livraison non effectuée.
3.2 Les frais de livraison ne sont pas remboursés lorsque le client se rétracte après une livraison conforme, sauf si la rétractation intervient dans le délai de 7 jours (frais d'expédition initiaux remboursés).

## 4. Moyen de remboursement selon le paiement
4.1 **Carte de crédit** : remboursement sur la même carte. Le crédit apparaît sur la facture dans un délai d'un à deux cycles de facturation.
4.2 **Carte de débit** : remboursement sur le compte sous 5 à 10 jours ouvrés.
4.3 **Boleto bancaire** : virement bancaire. Le client doit fournir ses coordonnées bancaires dans un délai de 15 jours ; sans réponse, un avoir est créé.
4.4 **Voucher / avoir** : le montant est recrédité sous forme d'avoir, valable 12 mois.

## 5. Paiement en plusieurs fois
5.1 Pour un paiement en plusieurs échéances, le remboursement est réparti sur les échéances déjà prélevées ; les échéances à venir sont annulées.

## 6. Litiges
6.1 Si le client conteste le montant remboursé, il peut ouvrir une réclamation auprès du service client dans un délai de 30 jours.
